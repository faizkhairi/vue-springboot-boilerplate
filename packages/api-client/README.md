# @repo/api-client

A TypeScript Axios client generated from the backend's OpenAPI specification, using `openapi-generator-cli`.

This package is optional: the frontend app does not import it today. It exists for projects that want a typed client instead of hand-written Axios calls.

## Contract-First Design

1. **Backend serves an OpenAPI spec** at `/api-docs`, generated by springdoc-openapi from Spring annotations
2. **openapi-generator-cli produces a TypeScript client** from that spec
3. **A project can import the typed client** for type-safe API calls, instead of writing Axios calls by hand

## Setup

```bash
cd packages/api-client
npm install
```

## Generate Client

### Prerequisites

The backend must be running so its OpenAPI spec can be fetched:

```bash
cd backend
export JWT_SECRET=$(openssl rand -base64 48)
./gradlew bootRun
```

Then, from the backend directory, fetch the spec into `build/openapi.json` (the path `openapitools.json` expects):

```bash
curl http://localhost:8080/api-docs -o build/openapi.json
```

### Generate TypeScript Client

```bash
cd packages/api-client
npm run generate
```

This reads `../../backend/build/openapi.json` (configured in `openapitools.json`) and generates TypeScript interfaces and Axios API classes in `src/generated/`.

## Usage in Frontend

```ts
import { AuthApi, Configuration } from '@repo/api-client'
import type { LoginRequest, TokenResponse } from '@repo/api-client'

// Configure base URL
const config = new Configuration({
  basePath: import.meta.env.VITE_API_BASE_URL || 'http://localhost:8080'
})

// Create API instance
const authApi = new AuthApi(config)

// Make type-safe API calls
const response = await authApi.login({
  email: 'user@example.com',
  password: 'password123'
})

const tokens: TokenResponse = response.data
```

## Workflow

1. **Add or change an endpoint in Spring Boot.**
2. **Start the backend and fetch the spec** (see Prerequisites above): `curl http://localhost:8080/api-docs -o build/openapi.json` from `backend/`.
3. **Regenerate the TypeScript client**: `npm run generate` from `packages/api-client/`.
4. **Use the regenerated client** wherever it is imported, with the updated types.

## Notes

- Zero manual typing: request and response types come from the backend's OpenAPI spec, not hand-written interfaces.
- Type safety: a changed API contract shows up as a TypeScript error at compile time, once this package is actually imported somewhere.
- The backend is the single source of truth for the contract; this package is a generated artifact, not something to hand-edit.
- `src/generated/` is produced by `npm run generate`; treat it as a build output, not something to hand-edit, and regenerate it whenever the backend's API changes.
